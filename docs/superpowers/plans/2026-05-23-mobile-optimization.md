# Mobile Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every public route fully functional, stable, readable, and performant on mobile.

**Architecture:** Treat mobile as a first-class responsive mode rather than a scaled-down desktop. Keep the current desktop art direction intact, but replace narrow-screen sticky/parallax/hover-first experiences with touch-native layouts, safe-area spacing, and deterministic mobile browser checks.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind CSS v4, Framer Motion, GSAP ScrollTrigger, Lenis, Next Image, Playwright mobile verification.

---

## Relevant Skills

Use @superpowers:executing-plans or @superpowers:subagent-driven-development for implementation. Use @playwright-testing for the mobile verification suite, @fixing-motion-performance for Lenis/GSAP/mobile animation changes, and @frontend-tailwind-best-practices for responsive Tailwind edits.

## Current Findings

- `src/app/globals.css` sets `html { zoom: 90%; }`, which can distort mobile viewport math, text rendering, fixed overlays, and tap targets.
- `src/hooks/useIsMobile.ts` marks any touch-capable device as mobile, including tablets/laptops with touch screens. It also starts as `false`, so mobile-only branches can flicker after hydration.
- `src/components/LenisProvider.tsx` enables smooth wheel/touch scrolling globally. Mobile browsers already have native inertial scrolling, and Lenis can fight `position: fixed`, sticky panels, and input focus.
- `src/components/ParallaxGallery.tsx` and `src/components/ParallaxCards.tsx` use desktop-style sticky/parallax scenes on mobile. These should become simpler vertical/touch layouts below `md`.
- `src/components/VideoBackground.tsx` still loads the hero MP4 on mobile after a delay. Mobile should use the poster by default unless a later requirement asks for video.
- `src/components/appointment/*` needs stronger 44px tap targets, mobile progress layout, full-width actions, and no tiny horizontal affordances.
- `src/components/lookbook/LookbookGallery.tsx` and `src/components/journal/JournalGrid.tsx` use wrapped filter groups that can dominate small screens. Use horizontal chip rails on mobile.

Replace `src/hooks/useIsMobile.ts` with:

```ts
"use client";

import { useEffect, useState } from "react";

export function useIsMobile(breakpoint = 768) {
    const [isMobile, setIsMobile] = useState(false);

    useEffect(() => {
        const query = window.matchMedia(`(max-width: ${breakpoint - 1}px)`);
        const update = () => setIsMobile(query.matches);

        update();
        query.addEventListener("change", update);
        return () => query.removeEventListener("change", update);
    }, [breakpoint]);

    return isMobile;
}
```

- [ ] **Step 5: Add reduced-motion hook**

Create `src/hooks/usePrefersReducedMotion.ts`:

```ts
"use client";

import { useEffect, useState } from "react";

export function usePrefersReducedMotion() {
    const [prefersReducedMotion, setPrefersReducedMotion] = useState(false);

    useEffect(() => {
        const query = window.matchMedia("(prefers-reduced-motion: reduce)");
        const update = () => setPrefersReducedMotion(query.matches);

        update();
        query.addEventListener("change", update);
        return () => query.removeEventListener("change", update);
    }, []);

    return prefersReducedMotion;
}
```
